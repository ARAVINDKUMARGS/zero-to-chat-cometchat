# DevConnect — 85-second demo script

Setup before recording: server and client running. Two windows side by side: **Alice** (left) and **Bob** (right), both already signed in, both on the People tab. Zoom browser to 110%.

| Time | On screen | Say |
| --- | --- | --- |
| 0:00–0:10 | Login screen, then sign in as Alice | "Developers lose hours to scattered chat. DevConnect is a real-time collaboration hub for dev teams, built on CometChat." |
| 0:10–0:22 | Alice's sidebar: Projects tab, click `# frontend` | "Each project gets its own channel: frontend, backend, code review, hackathon team. Users join automatically, and the server issues a secure token, so no secret keys ever reach the browser." |
| 0:22–0:40 | Bob types in `# frontend` (don't send), point at Alice's header | "Watch Alice's header. Bob starts typing, and Alice sees it live. That's CometChat's real-time typing indicator." |
| 0:40–0:55 | Bob sends a message, it lands in Alice's window instantly. Alice replies. | "Messages arrive instantly in both windows. No refresh, no polling." |
| 0:55–1:08 | Alice → People tab, point at Bob's online dot. Click Bob, send a DM. | "Presence shows who's online right now. Click a teammate to start a private conversation." |
| 1:08–1:18 | Shrink window to phone width, show list → chat → back | "It's fully responsive, so it works on a phone too." |
| 1:18–1:25 | Show the architecture or repo | "React and Vite on the front end, a tiny Express server for secure auth, CometChat for everything real-time. That's DevConnect." |

Tips: rehearse once with a timer; if you run long, cut the mobile segment. Record at 1080p, mute notifications.
